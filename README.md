# FinCart – Personal Finance REST API

FinCart is a personal finance REST API built using Java and Spring Boot. It helps users manage their expenses with secure authentication and user-specific expense tracking.

### Features
- User registration and login using JWT authentication.
- Secure password hashing with BCrypt.
- Create, view, update and delete expenses.
- Pagination, sorting and category-based filtering.
- User-specific expense access and ownership validation.
- Centralized exception handling.
- PostgreSQL database integration.
- Docker and Docker Compose support.

### Tech Stack
Java 21 · Spring Boot · Spring Security · JWT · BCrypt · Spring Data JPA · Hibernate · PostgreSQL · Docker

### Running Locally
1. Clone the repository.
2. Configure PostgreSQL and environment variables.
3. Run the application using IntelliJ or Maven.

```bash
mvn spring-boot:run
```

### API Base URL
`http://localhost:8080/api`

Built to practice backend development, REST API design, authentication, database integration and containerization.
